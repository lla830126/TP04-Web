# 인간이 없는 사회

사람은 가득한데 **인간만 없다.**

대륙 하나, 거점 48곳, 나라 10개. 사람 1,758명이 아침마다 오늘 무엇으로 벌어먹을지 고르고,
굶으면 숲을 뒤지고, 아프면 눕고, 잃을 것이 없어지면 길로 나선다. 왕은 달마다 금고를 보고
조일지 풀지 정하고, 길드장은 장날마다 값을 받칠지 곳간을 열지 정하고, 마물의 여왕은
계절마다 어느 마을을 물지 고른다.

아무도 다음 일을 지시하지 않았는데 사슬이 끝까지 흐른다. 그 안에 플레이어는 없다.

관찰창에서 **거점을 누르면** 다스림·사이·곳간·사람·환경이 나오고, **사람을 누르면**
그가 오늘 저울에 올린 선택지가 점수까지 나온다 — 고른 것만이 아니라 고르지 않은 것까지.

```
제 일  8.09  ← 골랐다
    기대 보상 × 4.28
    연장 (세기 1.00) × 1.25
    숙련 (세기 0.50) × 1.23
사냥 — 밑천이 없다 (armed)
```

## 만든 방식

판단이 하나의 저울로 모인다. 사람도 왕도 길드장도 같은 식으로 고른다:

```
점수 = 기대 보상 × Π(환경 배수) × (1 − 위험 × 조심성)
```

다른 것은 후보 목록과 저울에 오르는 환경 요소뿐이다 — 일곱 층, 행동 34종, 가중치 160줄,
요소 43종(계절·역병·흉년·혹한·잠식·도적·굶주림·무장·숙련·이름값·금고·전쟁 피로 …).

이벤트는 서로를 부르지 않고 세계 상태를 매개로만 이어진다:
흉년 → 곳간 → 굶주림 → 산적 → 호위.

백 년을 돌리면 나라가 서고 무너지고 이웃에 몸을 의탁하며, 왕조가 이어지고 끊기고,
마물의 여왕이 베이고, 밀수꾼이 닫힌 문으로 넘는다.
